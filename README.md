# GoIT Markup Homework #5

This project is the fifth homework assignment within the GoIT Full Stack Developer program. It focuses on implementing HTML forms, modal windows with backdrop structure, custom-styled checkboxes using SVG sprites, smooth transitions (`cubic-bezier`), and interactive focus/hover states.

## 🚀 Live Demo
- [View Live Page](https://meryemozkan1.github.io/goit-markup-hw-05/)

## 🛠️ Technologies & Tools Used
- **HTML5 & CSS3:** Semantic markup, form validation attributes, flexbox, custom modal positioning, and backdrop states.
- **SVG Sprites:** Vector icons (`icons.svg`) for inputs, buttons, and custom checkbox elements.
- **modern-normalize:** CSS reset/normalizer.
- **Google Fonts:** Raleway and Roboto integration.
- **Prettier:** Code formatting.
- **Git & GitHub:** Version control and GitHub Pages deployment.
